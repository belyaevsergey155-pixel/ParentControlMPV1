# Мой Контроль — Android MVP 0.1

Первая демонстрационная версия приложения родительского контроля.

## Сборка APK
1. Установите Android Studio.
2. Откройте папку `ParentControlMVP`.
3. Дождитесь синхронизации Gradle.
4. Выберите `Build → Build APK(s)`.
5. APK появится в `app/build/outputs/apk/debug/`.

## Уже есть
- режим Родитель / Ребёнок;
- лимиты YouTube, Minecraft и Roblox;
- изменение лимита;
- включение/выключение правила;
- переход к системному Usage Access;
- демонстрационная кнопка блокировки;
- ночной режим как настройка интерфейса.

Это MVP-интерфейс. Реальная удалённая синхронизация двух устройств и системная блокировка приложений — следующий этап.
